# DISCO 新舞厅 · 自由经营扩展

[开始游戏](https://sunwenxuan18-hash.github.io/disco-game/next/) · [最初完整复刻](https://sunwenxuan18-hash.github.io/disco-game/)

这次更新替换原地址的旧升级预览。最初的完整复刻仍保留在网站根目录。

- 自由经营：三级场地、舞池/吧台/休息区、四类员工、工作经验和手动晋升、声望与成长目标。
- 永久升级只补差价；装修与设备容量分开。经典配色之外，可购买霓虹、热带主题，并在各区域的 4×3 网格内摆放、移动或收纳装饰。
- 速度支持 0.5× / 1× / 2× / 5×。自由模式每夜 180 模拟秒，菜单暂停现场经营，倍速不放大离线收入。
- 离线每现实小时先折算一夜，再按前2小时80%、2–6小时50%、6–12小时20%、12–24小时5%衰减，连续24小时后停止。短暂打开不会重置高收益段。经理可有限改善效率，也需要工资；离线不增加经验或声望。
- 新贷款每夜按剩余本金计息1%，累计利息最多为最初本金的10%；正经营利润20%自动还款，也可主动部分还款或结清，结清后无后续利息。
- 资金紧张时可基础自营，保留设备、员工和债务，不再免费赠款或清债。
- 经典三关保留独立存档。旧自由模式会迁移资产和资金，从更新后开始计算离线收入；旧贷款已含旧版费用，不重复追加新版利息。

在 iPhone Safari 中打开，选择“分享 → 添加到主屏幕”。首次联网完成离线资源准备后，可以从主屏幕或浏览器离线打开。存档只在当前设备和浏览器中，清除网站数据会删除进度。主动暂停或返回开始画面也会停止后续离线经营。
